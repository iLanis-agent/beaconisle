# Beaconisle 1.0 TEST
Native Java/Canvas Android 8+ Lighthouses-style ship-placement puzzle.

Place single-cell ships on blank tiles. Each numbered lighthouse counts all ships in its row and column, including those behind other ships or lighthouses. Every ship must share a row or column with at least one lighthouse. Ships cannot touch other ships or lighthouses, even diagonally. Numbered towers stay fixed. Tap a blank tile to place or remove a ship. Twelve unique 4x4 clue boards have twelve distinct solutions, each with two ships.

Saved beacon palette and ship marks, GG007 icon/menu/site/privacy, unlimited undo/reset. Offline, no ads, analytics, requested permissions or account. Settings and completion marks stay on device. External studio link opens browser.

Independent Java coordinate-neighborhood and visible-set oracle checks all 65536 occupancy masks per board against production pairwise distance and row/column counting, confirming one solution each. Fixed cells, bounds, toggle, solve, undo and replay pass. Adapter menu, settings, privacy, tile taps, next, levels and persistence pass. Actual drawing-code pixels inspected, not phone screenshots.
